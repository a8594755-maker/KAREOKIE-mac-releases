# KAREOKIE for Mac

Free AI karaoke software and singing scores for **Macs with Apple silicon (M1 or later), macOS 26 or later**.

**[Official website](https://kareokie.com/) · [All Mac releases](https://github.com/a8594755-maker/KAREOKIE-mac-releases/releases) · [Windows version](https://github.com/a8594755-maker/KAREOKIE-releases)**

> The Mac version is coming soon. This repository will hold its installers and automatic updates.

- Import your own audio or video files and separate vocals from the backing track with AI.
- Follow synchronized lyrics, including furigana for Japanese songs.
- Practice singing with live microphone pitch scoring and a report after each song.
- Keep song processing and audio on your own Mac, accelerated on Apple silicon.
- Use the app in English, Traditional Chinese or Japanese.

## Downloads and updates

Each release here has `KAREOKIE-x.y.z-mac-arm64.dmg`: open it and drag KAREOKIE to Applications. The app is signed with a Developer ID and notarized by Apple. The installed app checks this repository for updates automatically and shows a notification when a new version is available. Intel Macs are not supported.

See the website for [system requirements](https://kareokie.com/#requirements), [frequently asked questions](https://kareokie.com/#faq) and the [changelog](https://kareokie.com/#changelog).
